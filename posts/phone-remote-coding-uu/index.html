真正顺手的手机远程 AI 编程只要一步：UU 远程 + Claude Code 移动工作流

2026-05-19 · 约 3 分钟读完 · X 217K 阅读
移动工作流 远程开发 Claude Code 实战帖

突然发现之前折腾什么Tailscale+tmux，claude remotion，codex远程全他妈浪费时间。

这才是终极的手机AI远程，目前体验下来最舒服的产品。100%跟你本地电脑一致。

网易 UU 远程。专业远程软件。

几乎 0 延迟，8个分屏一起盯都不卡。 手机点一下，Mac 屏幕同步响应，跟坐在电脑前没区别。

先说为什么要折腾这事：

Agent 写代码是长流程，跑一次 30 分钟起步。 你不可能一直坐在电脑前看它干活，但又得随时能介入—— 改一句 prompt、看一眼报错、确认一下 plan。 这种"半监督"状态最适合手机远程。

但市面上的远控方案，没一个是真为这个场景设计的：

claude remotion： 这破玩意儿极其不稳定，是个半成品。

codex app remotion： 单session还好，没有分屏，而且没办法操控codex cli。

Tailscale + tmux +mosh：适合偶尔看一眼，不适合连续操作。环境跟你开发环境不一致，经常卡顿。

微软远程桌面：协议本身没问题，但没有公网穿透。配置门槛劝退。

试到 UU 远程的时候是抱着试试看的心态—— 他们积累了大量的网络加速能力。 结果反过来：因为底层网络是按游戏延迟做的，远控反而吊打一众"正经"远控软件。

使用方式简单到不需要教程：

  1. 手机和电脑各装一个 UU 远程（iOS / Android / Mac / Windows 全平台，免费无广告）
  2. 同账号登录，手机端选中电脑就连进去了
  3. 直接用语音输入法对 Claude Code / Codex 喊指令

我现在的工作流，轻量版：

tmux启动Claude Code，平时出个门什么或者中午散步，用UU的终端功能，tmux共享session。

用终端功能跑Claude Code长任务，这个非常省流量，再配合语音输入法，效率跟电脑上一摸一样。

这套方式比codex远程和tailscale组网，网络都要顺畅，丝滑。

我现在的工作流，标准版：

通勤路上手机连进去，有问题语音补一句 prompt。 咖啡店坐下来就是 8 个分屏并行—— 一个跑后端、一个跑前端、一个跑测试、一个看日志、剩下的开着 Codex 处理小任务。 人只负责说话、看、点头。

手机语音输入法 + UU远程到 Mac 上的 agent。

这套已经成了我出门时的默认配置。 分享给同样在折腾 mobile-first AI 工作流的人。

我之前也用taiscale，前两个月把它丢垃圾桶了
