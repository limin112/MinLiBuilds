用 crontab 锁死 Claude Code 的 5 小时额度重置窗口

2026-04-05 · 约 3 分钟读完 · X 193K 阅读
Claude Code 额度工程 crontab 实战帖

有没有人跟我一样？

Claude Code 5小时重置一次，并以当天第一次使用开始计算周期。

我会使用crontab每天早上7:01定时用Haiku发一句“早安”。

这样一来，每5小时重置被我锁定在7-12点，12-17，17-22。

上午游刃有余，下午午休后不急不忙，傍晚17点再重置一次
