用 /schedule 云端定时触发 Claude Code 额度重置（免开机版）

2026-04-09 · 约 3 分钟读完 · X 110K 阅读
Claude Code 额度工程 /schedule 实战帖

小天才来了。

花一分钟设置，利用Claude Code 5小时重置一次的机制，让你每天9～12点，午休后14～17点，17～下班前从容不迫使用容量100%的token window。

比crontab更好的方法。我会让Claude云端执行定时任务，本地不用打开电脑。

方法1: 在Claude Code里： /schedule 每天7点5分、12点5分、17点5分用Haiku说一句 only say hello to me

方法2: 你也可以去https://claude.ai/code/scheduled/直接手动创建schedule
